## 4. Approach & methodology  (the *how*)
<!-- For the team to trust and reproduce the numbers. Concise, factual. -->

1. **Migration.** Hand-written SYCL 2020 (no dpct/SYCLomatic). <Target-style decisions.> Each kernel
   validated against a CPU-oracle reference before acceptance; every accepted change is a git commit.
2. **Integration.** SYCL was added as a **backend of the project** — the backend switch, the device
   runtime layer over SYCL, and the build wiring were built *before* the kernels were ported, so each
   kernel landed on a live dispatch path rather than in a standalone tree. <Which surfaces were
   closed; what the host-port sweep cost; which host libraries were replaced.> Depth is reported as a
   Backend Readiness Level in §3.4, computed from run records — not asserted.
3. **Ranking.** End-to-end profiled with unitrace (host + device timing), scoped to representative
   iterations to stay crash-safe; kernels ranked by wall-clock share to set optimization priority.
4. **Optimization.** Highest-impact first, against a **standalone single-kernel benchmark** across
   representative shapes. Each kernel **diagnosed** first (HW metric counters + stall sampling + IGC
   asm) to find the true bottleneck, then **one** change per trial, kept only if it wins across shapes
   (else reverted). Trials recorded in `.sycl/state/optimization/<id>.json`.
5. **Verification.** Correctness re-checked after every optimization; final e2e re-profiled for the
   baseline→final comparison in §3.1.
6. **Evidence.** Every figure in §3 was produced by a captured command: the raw log, exit code, commit
   and machine fingerprint are stored under `.sycl/reports/evidence/` and indexed in
   [`AUDIT.md`](AUDIT.md). Re-run `.sycl/scripts/evidence.sh verify` to re-hash every log and re-check
   every claim in this report — nothing here needs to be taken on trust.
